# 聖華编年史

*Shenghua Chronicles*

> 聖華公会历史记录、成员纪事与长期记忆库。

------

## 项目简介

**聖華编年史** 用于记录聖華公会的发展历程、重要事件、成员故事、经典语录与值得被记住的历史瞬间。

本仓库同时作为 AI 可检索知识库设计，支持使用 Codex、OpenCode 等工具进行事件查询、人物检索、时间线整理与历史总结。

记录范围主要包括：

- 公会重大历史事件
- Boss击杀与阶段里程碑
- 周年活动与大型集体活动
- 成员个人事件与名场面
- 成员档案与人物关系
- 经典语录、名台词与梗出处

------

```txt
shenghua-chronicles/

```

------

## 公会历史事件

路径：

```txt
guild-events/
```

用于记录具有公会纪念意义或历史价值的事件。

例如：

- Boss首杀
- 高难击破
- 周年活动
- 大型团建

建议命名：

```txt
YYYY-MM-DD-事件名称.md
```

------

## 成员个人事件

路径：

```txt
personal-events/
```

用于记录成员相关事件、趣事、名场面与经典历史。

例如：

- 翻车现场
- 搞子逸闻
- 经典操作
- 社死瞬间
- 长期流传梗
- 特殊成就

建议命名：

```txt
YYYY-MM-DD-成员名-事件名称.md
```

------

## 成员档案

路径：

```txt
members/
```

用于维护成员长期人物记录。

建议包含：

- 常用ID
- 曾用名 / 绰号 / 别称
- 入会时间
- 著名事件
- 经典语录
- 关联记录
- 人物简介

------

## 经典语录 / 名台词

路径：

```txt
quotes/
```

用于记录公会文化中长期流传的经典发言、名台词与梗出处。

例如：

- 指挥名言
- 团灭预言
- 迷惑发言
- 长期流传内部梗

建议命名：

```txt
YYYY-MM-DD-发言人-语录关键词.md
```

示例：

```txt
2026-06-03-某成员-我知道路.md
2026-06-18-团长-这波不可能灭.md
```

建议记录内容：

- 原始发言
- 发言人
- 时间与场景
- 事件背景
- 后续传播情况
- 关联事件

------

timeline/

- 公会历史年表

## 外部媒体资源

本仓库不直接存储视频、GIF、截图等大型资源。

媒体资料统一采用外部存储方式（如 Bilibili）。

相关记录建议在事件文件中保存：

- 视频链接
- BV号
- 时间点
- 内容说明
